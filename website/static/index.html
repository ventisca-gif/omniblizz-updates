Antes de empezar

¿Cómo juego?

Pulsa Jugar, elige modo y perfil, y utiliza los controles que aparecen en el juego. Habla con los NPC para encontrar misiones. Revisa los niveles recomendados antes de entrar a una zona nueva.

¿Se conserva mi partida entre Android y web?

Los datos locales pertenecen a cada instalación o navegador. Para trasladar progreso, utiliza las funciones de guardado y recuperación del juego y espera la confirmación. No publiques tu código personal.

¿La página necesita instalación?

La versión web se abre en el navegador. La APK es para Android. El primer arranque web descarga recursos; usa una conexión estable. Cambiar la dirección de la página puede crear un almacenamiento local distinto.
