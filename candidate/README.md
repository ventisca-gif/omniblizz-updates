# Propuesta de nueva versión Original

Para una futura actualización, colocar aquí `game.js` y `release.json` **en una rama de trabajo**, después de comprobar la última release y revisar que no incluyan credenciales.

Este repositorio es **público**, por lo que **nunca** se deben añadir respaldos privados, claves OTA, contraseñas o el keystore Android.

Ver [las instrucciones de automatización](../automation/README.md). Por ahora no hay candidato: la CI solo verifica la última release 2.43.26 sin publicar nada.
